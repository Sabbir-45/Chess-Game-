# 🎮 AI Game Project using Pygame

This project demonstrates an implementation of Artificial Intelligence techniques using **Python** and **Pygame** in a game environment. The AI utilizes search algorithms like **Minimax** with **Alpha-Beta Pruning** to make strategic decisions.

## 🧠 Key Features

- Built with **Pygame** for interactive GUI
- **Player vs Player** and **Player vs AI** modes
- AI powered by **Minimax Algorithm** with Alpha-Beta Pruning
- Move history and game timer support
- Clean and responsive game interface

## 🖥️ Requirements

- Python 3.x
- Pygame
